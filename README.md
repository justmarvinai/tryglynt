# Glynt

**Your daily nutrition, complete.** Glynt is a privacy-first nutrition companion — not a diet app. It tracks calories, macronutrients and the full panel of vitamins & minerals against your personal daily needs, computed from your body and lifestyle.

- 📱 Mobile-first PWA — installable, fully offline, no account, no backend
- 🔒 All data on-device (IndexedDB) with export/import backups
- 🧬 Personal targets: energy, macros + 26+ micronutrient reference values (EFSA/NIH)
- 🎨 Built on the [CleanOS](https://github.com/EinPallux/CleanOS) design system — clean, iOS-inspired, monochrome + one accent
- ⚡ Vite · React 19 · TypeScript · Tailwind CSS v4 · Dexie — deployed on Vercel
- 📦 Native iOS/Android via Capacitor planned after v1 is complete
